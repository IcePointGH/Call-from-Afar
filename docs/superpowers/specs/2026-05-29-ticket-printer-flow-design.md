# Ticket Printer Flow Design

## Goal

通话结束后先出现电话亭内置打印机，用户点击打印按钮触发出票动画，点击刚打印出的票根后再进入精致票根详情页。

## Interaction

- 通话结束弹层显示一个电话亭内部的出票机，而不是直接跳转到详情页。
- 打印机有三个状态：待打印、打印中、已出票。
- 用户点击“打印票根”后，按钮下压回弹，机器指示灯变亮，纸张从出票口推出并落位。
- 出票完成后，纸张变成可点击的预览票根；点击后进入 `/ticket`。
- `/ticket` 只展示精致票根详情和保存、打印、分享等操作。

## Scope

这是流程级交互重构，不是单页动效补丁。新增 `TicketPrinter` 作为稳定组件，避免把通话结束弹层、打印状态和票根详情导出逻辑混在同一个组件中。

## Reduced Motion

当用户关闭动画或系统偏好减少动态效果时，打印机仍保留状态变化：按钮变为禁用、票根直接出现、点击票根进入详情。
